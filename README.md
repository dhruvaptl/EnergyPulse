# EnergyPulse — Enhanced Campus Energy Intelligence Frontend

This version incorporates the visual and functional directions from the supplied reference dashboards:

- Premium green / neutral energy dashboard aesthetic
- Sidebar workspace navigation
- Overview dashboard with KPI cards, power-flow chart, energy mix, energy-flow diagram, building consumption, carbon offset, smart devices and weather impact
- Dedicated Consumption, Generation, Battery & Storage, Assets, Live Monitoring, Analytics & ML, Records, Reports, Alerts, Data Sources and Settings pages
- Solar generation visual, battery state-of-charge display and device status cards
- Proposed meter-to-dashboard architecture pipeline
- R model reference metrics from the EnergyPulse analysis
- Manual energy record entry, filtering, CSV export and report previews
- Bright / dark mode and responsive mobile layout

## Run

Open `index.html` in a browser. No build step is required.

## Prototype note

The values are simulated or historical demonstration values. Live meter, inverter, API, database and model-serving integrations remain future extension points.
